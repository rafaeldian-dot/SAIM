# SAIM - Sistema de Automacao de Instrucoes Militares

## Sobre o projeto

O SAIM e um software desktop desenvolvido em Python com o objetivo de automatizar o cadastro, a organizacao e o gerenciamento de instrucoes.

O projeto busca reduzir processos manuais e facilitar a organizacao de informacoes por meio de uma interface grafica e da geracao de planilhas Excel.

## Funcionalidades

- Cadastro de instrucoes.
- Organizacao de instrucoes por data.
- Registro de instrutor e destinatario.
- Organizacao semanal.
- Geracao de planilhas Excel.

## Tecnologias utilizadas

- Python
- CustomTkinter
- SQLite
- OpenPyXL
- Git e GitHub

## Instalacao

1. Instale o Python.
2. Clone este repositorio.
3. Instale as dependencias:

pip install -r requirements.txt

4. Execute o programa:

python main.py
